# Historical Research Experiments

This directory contains monolithic orchestration and ablation scripts from the original research and evaluation phase:

- `run_experiment.py`: Monolithic historical script used to extract features, evaluate diverse ML classifiers across commit strides, and benchmark semantic coverage.
- `settings.json`: Configuration used during historical experiment runs on Django.

For library usage and production applications, refer to the high-level `predictive_semantic_cache` package and the copy-pasteable scripts in `examples/`.
